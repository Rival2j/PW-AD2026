
| Etiqueta | ¿Para qué sirve? | Sintaxis | Ejemplo |
|---|---|---|---|
| `<h1>` | Encabezado principal | `<h1>Texto</h1>` | `<h1>Mi página</h1>` |
| `<p>` | Párrafo de texto | `<p>Texto</p>` | `<p>Hola mundo</p>` |
| `<a>` | Enlace/hipervínculo | `<a href="url">Texto</a>` | `<a href="https://github.com/Rival2j">Ir</a>` |
| `<img>` | Insertar imagen | `<img src="ruta" alt="desc">` | `<img src="src/foto.jpg" alt="Foto">` |
| `<div>` | Contenedor genérico | `<div>Contenido</div>` | `<div class="caja">Hola</div>` |
| `<span>` | Contenedor en línea | `<span>Texto</span>` | `<span>Palabra</span>` |
| `<ul>` | Lista sin orden | `<ul><li>Item</li></ul>` | `<ul><li>Manzana</li><li>Pera</li></ul>` |
| `<ol>` | Lista ordenada | `<ol><li>Item</li></ol>` | `<ol><li>Paso 1</li></ol>` |
| `<li>` | Elemento de lista | `<li>Texto</li>` | `<li>Pan</li>` |
| `<table>` | Crear tabla | `<table>...</table>` | `<table><tr><td>1</td></tr></table>` |
| `<tr>` | Fila de tabla | `<tr>...</tr>` | `<tr><td>Dato</td></tr>` |
| `<td>` | Celda de tabla | `<td>Texto</td>` | `<td>Nombre</td>` |
| `<form>` | Formulario | `<form action="url">...</form>` | `<form><input></form>` |
| `<input>` | Campo de entrada | `<input type="text">` | `<input type="nombre">` |
| `<button>` | Botón interactivo | `<button>Texto</button>` | `<button>BOTON</button>` |
| `<label>` | Etiqueta para input | `<label for="id">Texto</label>` | `<label for="nom">Nombre</label>` |
| `<head>` | Metadatos del documento | `<head>...</head>` | `<head><title>X</title></head>` |
| `<body>` | Contenido visible | `<body>...</body>` | `<body><h1>Hola</h1></body>` |
| `<strong>` | Texto en negrita (énfasis) | `<strong>Texto</strong>` | `<strong>Importante</strong>` |
| `<br>` | Salto de línea | `<br>` | `Línea 1<br>Línea 2` |
